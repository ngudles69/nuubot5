# Nuubot5 Handoff Router

Read this file completely.

If the exact worktree directory is `nuubot5`, read `HANDOFF-MAIN.md`.

If the exact worktree directory is `nuubot5-server`, read
`HANDOFF-SERVER.md`.

Use only the applicable worktree handoff for `DONE`, `TODO`, and
`PENDING USER APPROVAL` state.

If handoff state conflicts with applicable instructions, stop the affected work
and raise the conflict with the user immediately.
