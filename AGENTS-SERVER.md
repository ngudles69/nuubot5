# Nuubot5 Server Worktree Instructions

These instructions apply only when the exact worktree directory is
`nuubot5-server`.

Read `HANDOFF-SERVER.md` for current server-worktree state.

Keep server-worktree `DONE`, `TODO`, and `PENDING USER APPROVAL` state only in
`HANDOFF-SERVER.md`.

Do not import main-worktree task state into server-worktree task state.
