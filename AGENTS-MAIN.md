# Nuubot5 Main Worktree Instructions

These instructions apply only when the exact worktree directory is `nuubot5`.

Read `HANDOFF-MAIN.md` for current main-worktree state.

Keep main-worktree `DONE`, `TODO`, and `PENDING USER APPROVAL` state only in
`HANDOFF-MAIN.md`.

If `TMUX` is set, read `TMUX.md` and follow its startup contract.

The `TMUX.md` workspace bootstrap is approved startup work. It does not require
separate pre-action confirmation.
